# MHub

Cross-platform (Android, Windows, Linux, macOS) Flutter client for the
**MbunieEduHub** platform. One app for both **members** and **administrators** —
the UI adapts based on the signed-in user's role.

## Architecture

```
Flutter app (MHub)  ──HTTP/JSON + Bearer token──►  Laravel backend (..)
   prod/mhub/                                        prod/routes/api.php  (Sanctum)
```

- **State management:** `flutter_riverpod`
- **HTTP:** `dio` with an auth interceptor (`lib/core/api_client.dart`)
- **Token storage:** `flutter_secure_storage` (`lib/core/storage.dart`)
- **Auth flow:** `lib/features/auth/` — token issued by `POST /api/login`
- **Role routing:** `lib/features/shell/home_shell.dart` picks member vs admin
  navigation from `user.is_admin`

This Flutter project lives at `prod/mhub/`; the Laravel backend is its parent
`prod/` directory.

## Backend endpoints (already added to `prod/`)

| Method | Path                  | Auth            | Purpose                    |
|--------|-----------------------|-----------------|----------------------------|
| POST   | `/api/login`          | none            | Issue Sanctum token        |
| GET    | `/api/user`           | sanctum         | Current user               |
| POST   | `/api/logout`         | sanctum         | Revoke current token       |
| GET    | `/api/dashboard`      | sanctum         | Member dashboard data      |
| GET    | `/api/admin/dashboard`| sanctum + admin | Admin dashboard data       |

## Configuring the API base URL

The base URL is resolved in `lib/core/config.dart`. Override it at run/build time:

```bash
flutter run  --dart-define=MHUB_API_BASE=http://127.0.0.1:8123
flutter build apk --dart-define=MHUB_API_BASE=https://mbuniehub.com
```

Defaults when no define is given: `http://10.0.2.2` on Android (emulator
loopback), `http://localhost` elsewhere.

## Running in development

1. Start the Laravel backend (from `prod/`):
   ```bash
   php artisan serve --host=127.0.0.1 --port=8123
   ```
2. Run the app (from `prod/mhub/`):
   ```bash
   flutter run -d windows --dart-define=MHUB_API_BASE=http://127.0.0.1:8123
   ```

Test accounts (created in the dev DB):

|--------|--------------------------|---------------|

## App icon

The launcher icon is generated by `flutter_launcher_icons` from
`assets/icon/mhub_icon.png`.

The current file is a **placeholder**. To use the real MHUB logo:

1. Save the logo as a square PNG (1024×1024, transparent or solid background)
   to `assets/icon/mhub_icon.png`, replacing the placeholder.
2. Regenerate:
   ```bash
   dart run flutter_launcher_icons
   ```

`tool/make_icon.php` regenerates the placeholder if needed.
